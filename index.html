三条口径铁律

错了任意一条，结论必错
  1. 01
    缺失值不是 0，NaN 必须显式出现

    sum 全缺失时返回 NaN 而不是 0；mean 的分母是有效值个数而不是总行数。 把 NaN 写成 0，等于把「没数据」读成「业绩归零」。

  2. 02
    axis 方向决定语义，不只是排版

    axis=0 是「同一列跨行」聚合（各区域销售额合计）；axis=1 是「同一行跨列」聚合（每笔订单的金额合计）。 方向反了，整张表都要重算。

  3. 03
    小样本组不能并排比较

    组内 n < 阈值时均值方差极大，排名反映的是噪声。 工具会给这类组打上小样本标记，请勿据此下结论。

01三步跑通

  1. 载入数据：右上角「导入数据」选择 CSV / Excel（可多选，也可把文件拖进窗口）；想先看效果就点「重载示例」。
  2. 配置口径：左侧 A–G 七组配置。选主表 → 选度量列 → 选算子 → 展开「聚合方向」抽屉选 axis → 把字段拖进「行分组键」成为层级。
  3. 复核与导出：先看「口径体检」六项是否通过，再点「导出结果」勾选要交付的文件。

02关键操作

  • 导入：支持 CSV（自动嗅探 , ; Tab | 分隔与 UTF-8/BOM 编码）与 XLSX。导入的每个文件都会成为一个数据源。
  • 多源关联：在主表下拉里选事实表，维表按同名字段自动左连接；同名冲突列会加 @文件名 后缀。
  • 分组：字段可拖拽到「行分组键」/「列分组键」，也可点击字段芯片快速加入；点芯片上的 ✕ 移除。
  • 算子：可同时勾选多个，结果表按「度量·算子」展开成多列。
  • 方向：展开左侧「聚合方向」抽屉即可切换 axis=0 / axis=1，切换后结果语义整体改变，页面顶部与结果页会同步提示。
  • 图表：柱状 / 饼 / 折线 / 雷达四种。饼图要求单一系列、非负、2–12 组；折线图要求有序维度（日期或数值）；雷达图要求 ≥3 个维度且 ≥2 个指标。不满足会给出「不支持此类型图表」及原因。
  • 导出：Excel（汇总/明细/口径）、CSV 明细、口径声明 TXT、分析报告 HTML、图表 PNG、操作日志，可一次全选。

03口径约定（与导出文件一致）

  • 缺失判定：空串、-、--、N/A、NA、NaN、null、none、#N/A、「空」。
  • skipna=True：剔除缺失后计算，分母为有效值个数。False：组内存在缺失即返回 NaN。
  • 空聚合：有效值 0 个时 sum 返回 NaN（不是 0），并另给 min_count=0 的对照值。
  • numeric_only：True 剥离文本并计入 n_nonnumeric；False 遇到文本即中断（与 pandas 一致）。
  • std：样本标准差 ddof=1，n<2 时返回 NaN。
  • count / nunique：始终只统计有效值，不受 skipna 影响。
  • 小样本：组内记录数 < min_group（默认 5）标记 small_sample。

05工具局限性（务必阅读）

1. 只做描述性统计。不含显著性检验、置信区间、回归、预测。看到「均值差」不能直接说「显著」。

2. 不做缺失插补。工具只负责「怎么算」，不负责「补数据」。系统性缺失（如某门店整月未上报）会让结论失真，需回源处理。

3. 多源仅支持等值左连接。不支持模糊匹配、区间连接、多对多展开；连接键按文本比较，1 与 "1" 会归为同一键。

4. 分组键文本化。「上海」与「上海市」是两个组；建议先在上游标准化取值。

5. 建议单次 ≤ 200,000 行。浏览器端为全内存计算，超限请先在源端预聚合。

6. 数据不落盘。浏览器版所有计算在本机内存完成，不上传任何服务器；但刷新页面即丢失，请及时导出。

7. XLSX 导入需现代浏览器（Chrome / Edge 80+，依赖原生解压能力）。旧内核浏览器请改用 CSV，或使用桌面版。

8. 图表最多展示 12 组。组数过多时按值取 Top 12，完整数据请看结果表或导出的 Excel。

9. 不支持日期运算与时间窗口。日期列按文本参与分组；同比环比需先在上游生成期间字段。

06常见问题

Q：为什么均值和我手算的不一样？
先看 skipna：开启时分母是有效值个数（不含缺失行）。在「口径体检」P1 里能看到两种口径的差值。

Q：为什么某一组全是 NaN？
该组有效值 0 个（整组缺失），或关闭了 skipna 而组内存在缺失。悬停单元格可看原因。

Q：为什么某个组被标成小样本？
组内记录数小于左侧设置的 min_group 阈值，均值波动大，不建议参与横向排名。

Q：导出的 Excel 打不开？
本工具生成标准 xlsx（2007+ 格式）。若被安全软件拦截，请改用 CSV 或在桌面版中导出。

Q：接大模型提示「连接失败」？
看提示后半句：密钥无效 → 重新复制 Key（前后别带空格）；跨域或网络拦截 → 网页版受浏览器同源策略限制，请改用桌面版（走本机代理）或换支持跨域的接口；HTTP 404 → 检查 Base URL 是否以 /v1 结尾、模型名是否写对；HTTP 429 → 额度不足或触发限流。不填 Key 也能用内置口径库。
